# Features

## Account Activity

Shows recent account activity so commercial users can understand customer state before outreach.

Benefit: fewer manual checks across separate systems.

## Order Overview

Groups orders by account and status.

Benefit: faster order review and clearer handoff between commercial and operations users.

## Follow-Up Indicators

Highlights accounts that may need action.

Benefit: helps users prioritize work without scanning every account manually.

## Filters

Filters activity by territory, status, and date range.

Benefit: supports focused review during daily or weekly routines.
