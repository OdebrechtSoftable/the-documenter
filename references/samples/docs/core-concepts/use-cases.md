# Use Cases

## Prepare For Customer Outreach

1. Open account activity.
2. Filter by territory.
3. Review last activity and open orders.
4. Plan follow-up based on current status.

Related docs: [Features](./features.md)

## Review Order Progress

1. Open order overview.
2. Filter by status.
3. Check accounts with delayed updates.
4. Coordinate next action with operations.

Related docs: [Order Management](../modules/order-management.md)

## Build Weekly Follow-Up List

1. Filter accounts by recent activity.
2. Review follow-up indicators.
3. Export or record next actions in the commercial workflow.

## Limitations

Use cases must reflect repo-supported behavior. Do not add workflows that the app does not implement.
